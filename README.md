# 🚀 Desafios Diários de Java

Repositório dedicado à prática diária de **lógica de programação com Java**.

O objetivo deste projeto é fortalecer os fundamentos da programação por meio da resolução contínua de exercícios, evoluindo gradualmente de problemas básicos até desafios mais complexos.

---

## 🎯 Objetivo

Desenvolver consistência e domínio dos principais conceitos de programação, incluindo:

* Variáveis e tipos primitivos
* Estruturas condicionais (`if`, `else`, `switch`)
* Laços de repetição (`for`, `while`, `do-while`)
* Arrays e matrizes
* Métodos
* Strings
* Algoritmos clássicos
* Estruturas de dados básicas
* Programação orientada a objetos

---

## 📅 Metodologia

Todos os dias é resolvido pelo menos um desafio de programação em Java.

Cada exercício possui:

* Enunciado do problema
* Implementação da solução
* Comentários explicativos no código
* Possíveis melhorias ou versões alternativas

Essa abordagem permite acompanhar minha evolução e consolidar conhecimentos fundamentais para o desenvolvimento backend.
